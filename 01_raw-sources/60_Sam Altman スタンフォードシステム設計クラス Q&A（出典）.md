# 文字起こしの主要ポイント（読み取り・修正済み）

## 1. スケールは独自の品質を持つ

> キャリアで見た最も興味深いものはすべて、**スケールの創発特性** か、コンセンサスが「これ以上は機能しない」と思うはるか先までスケールが回报し続けることと関連していた。

- AI モデルのスケールだけでなく、賢い人を集める・企業・YC のバッチ内ネットワーク効果等、あらゆる領域で観察
- YC で「バッチあたり10社に減らすべき」という賢い人たちの声に逆らい、スケールした結果、バッチ内のネットワーク効果という**誰も発見していなかった創発特性**が現れた
- なぜこれが真なのか、満足のいく理論は持たないが、**経験的には真**。スケールを押し込める機会を見つけたら、深く探索すべき

### システム設計の課題: スケールすると壊れる

- スケールすると**予測不能な方法で加速して壊れる**
- 「 ambitions にやりすぎない・小さくしよう」と言う賢い人が常にいる
- OpenAI が AI モデルをスケールした際、10万・20万 GPU は前例がなく、エンジニアリング人材・資本要件・研究者の文化（「なぜ1プロジェクトに全部の計算資源を入れるのか」）など、**各障害を1つずつ分解して個別に対処**

## 2. 人間の側のシステム設計が一番難しい

- ハードウェアやソフトウェアでなく、**人間参加型のシステム設計が最もリファクタ困難**
- 明確なゴール・ゴールへの明確な計画・意思決定方法の明確な回答が重要
- 「深層学習のスケールに賭ける。間違っていれば失敗するが、やる。これが理由。これが到達した時の世界の姿」宣言が強力
- **人間は指数関数的思考に進化していない**。モデルが指数関数的に改善し続ける・収益が指数関数的に成長する・組織が指数関数的な複雑性を取り入れることを想像するのが困難。第一原理から人々と推論するのに時間がかかる

## 3. ChatGPT 誕生秘話

- GPT-3 は面白いデモだったが**製品が見つからなかった**。考え続け、試したが機能せず
- 「製品が見つからないから API にして、誰かが製品を見つけるのを待とう」→ 2020年夏に GPT-3 API ローンチ
- 当初トラクションなし。1ヶ月後、複数の開発者が同日に Twitter でバイラル化
- **GPT-3/3.5 は当時の興味の割に驚くほど悪かった**。人々は様々なことを試したが、意味的に機能したのは copywriting のみ
- ただ、開発者たちは API を製品でなく**チャット**に使っていた。より多くの人が「製品では使えないがチャットには使う」
- GPT-4 は完成済み・GPT-3.5 との中間の新モデルあり・instruction following の post-training を見つけた
- YC の原則「**よく使われるものを見て、それをやる**」→ チャットボットを構築
- リサーチデモとして他者にチャット製品を構築させ API に課金させる意図だったが、**爆発的にバイラル化**
- YC の学び「本当に成長し始めたものがまだ良くない時、保証されたヒット」
- 5日間トラフィックが上がり下がりを繰り返し、5日目に「これは緊急だ。良い意味の緊急。会社と製品を一度に構築しなければ」
- 2ヶ月の猛烈なスケール。まず計算費が尽きないよう課金（長期の答えでないが機能した）

## 4. モデル改善パイプラインの将来

- pre-training / mid-training / post-training / supervised feedback loop の現在のパイプラインは**確かに現在のものだが、 major rewrite が来ると期待**
- パイプラインとして起こるのはやや奇妙で、最適解とは感じない
- **究極の最適解は「AI の今日の研究問題」**
- 目標: 2025年9月までに50万 H100 相当 GPU を AI リサーチインターンとして使い、2028年3月までに完全なアーキテクチャを考える非常に才能ある研究者を持つ

## 5. AI をユーティリティ（公共事業）として売る

> 電気・インターネット・水のようなユーティリティを作る過程にいる。これはあまり起こらない。

電気のユーティリティ化の比喩:
- 電力会社は「電気を売る」と言わなかった —— 誰もそれが何か・なぜ欲しいか分からず、怖いもの（家に入ってきて殺す）に思えた
- 代わりに **「光（light）」を売った**。「あなたが得るのは電気でなく光。同じもので洗濯もできる」と
- 人々は「なぜそれが欲しいのか」と言ったが、「いつか服を洗ってくれる」と説明
- OpenAI も**「インテリジェンスを売る」と言うのは今のところ共鳴しない**。「光」に相当するものを見つける必要がある

## 6. スケールの限界と "idol you so"（皮肉への対応）

- 世界モデルは明らかに重要（ロボティクス等に必要）
- しかし**この時点で LLM に賭けないのはかなり見当違い**
- 何年も「これは機能しない・詐欺だ・会社は失敗する」と言い続ける Twitter トロールに、もはやイライラさえしない
- データは我々の側にかなり強い。「同じことを何度も繰り返すのが狂気」という諺の通り

### アイデンティティの罠

- **特定の信念（これが機能する/しない）にアイデンティティを結びつけると、科学や経験的結果があなたを否定しても手放せず、真実が見えなくなる**
- 両方向にとって重要なリマインダ

## 7. 教育への懸念

- ChatGPT ローンチ時、1年間の学生のチート期間の後、教育システムが自分を再設計すると予想した
- しかし**3年半経っても体系的な変化を見せていない** —— これは予測ミスだった
- pre-AI の世界のように教え評価し続けると、**批判的思考力の萎縮**をもたらす
- 思考を学ぶために、機械がより上手にできることをあえて教える価値のあるもの（書くこと・プログラミング）はある。しかしそれ以外は完全に変えるべき

## 8. スタンフォードでの思い出

- 1年生時に四半期ごとに3つのインターンシップをした。すべて異なる分野
- 幅広い分野の**浅い理解**を得られたことが、CS と物理だけでなかった視点を与えた
- 2年で中退したため取りたかった多くがあった

## 9. 3つの分岐点（今後10年）

### 分岐1: 民主化 vs 少数企業への集中（確率 80% 民主化）
- デフォルトでは少数の企業に集中し、地球の富の显著な割合を握る可能性
- それは明らかに悪く、OpenAI は強く推し戻す
- 少数企業への集中は **アラインメント失敗 で非常に脆弱な世界**
- 80%民主化パスに着地するが、強い安全メッセージと権力を集中したい人々が対抗
- **リスクを負ってでも SF のような未来を目指すべき。少数企業への集中は許容すべきでない**

### 分岐2: 分散コンピューティング
- 計算資源不足は現在深刻化しており、さらに悪化する可能性
- 計算が人々が必要とする**最も重要なユーティリティ**になる可能性
- 計算価格が需要と供給で高騰しすぎた時、分散コンピューティングとは何かという面白い分岐
- モデルが十分賢く低コストになれば需要は事実上無限。「優れた個人エージェントが100個欲しい」→ 大量の推論 → 計算資源不足

### 分岐3: 経済モデル（市民富裕基金）
- UBI よりも**所有権ステーク（citizens' wealth fund）**に興味
- 世界のレバレッジが労働から資本へ移り続ける中、資本のスライスを所有する仕組み
- 月々の固定現金配当でなく、企業のスライスを所有
- 起業家がスタートアップに投資した結果を見てきた。どちらのモデルが良いかはデータが示す

### 計算資源不足の現在
- H100 と Blackwell の長期予約とスポットの価格差は約5倍（改善したが依然高い）
- H100 は今年ほぼ全て売り切れ
- **人々はもっとパニックすべき**
- 電力と同様、価格が下がれば需要は全く異なる水準に。AI も同様 —— 十分に賢く低コストなら需要は無限
