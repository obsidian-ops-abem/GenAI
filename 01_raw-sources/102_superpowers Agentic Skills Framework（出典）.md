## 概要

superpowers は、Claude Code 等のエージェントが作業中に「自分用のskill」を書き足し、次のタスクで再利用していく構造のフレームワーク。ソフトウェア開発方法論そのもの。

### connect24h の評価

- 単なるプロンプト集ではなく、Agentic Skills Framework という**ソフトウェア開発方法論そのもの**
- エージェントが作業しながらskillを蓄積 → 次タスクで再利用
- **毎回ゼロから指示を書き直す運用 → エージェント自身が経験を蓄積して賢くなる運用** への転換
- CLAUDE.md を育てる感覚の延長線上にあるが、方法論として体系化されている分、再現性が違う
- AI駆動開発の運用効率化を考える人は Shell 実装の中身まで読むべき
