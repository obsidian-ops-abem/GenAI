## 概要

opc-skills は、1人会社・個人開発者向けの AIエージェント向け skill 集（⭐️約1.3千）。

### 特徴

- AIエージェント向けの skill 集
- SEO/GEO、需要調査、ドメイン探し、ロゴ作成などをまとめて拡張
- Claude Code / Cursor / Codex 等に対応
- 1人会社・個人開発者向けに実務寄りの自動化が揃う
- 「AIをただのチャットで終わらせず、実務で働かせたい」人に刺さる

### コメント欄の知見（田中｜AI×AWSで副業）

- skill集は増えてきた
- 効いたのは汎用のものより**「自分の環境の前提」を書いたやつ**: 使うクラウド・命名規則・ダメな書き方
- これを最初に固定しておくと、やり直しの回数がはっきり減る
- **拡張より先に、前提を書くほうが効く**
