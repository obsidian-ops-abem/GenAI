# raw-sources

ここに置くのは加工前の生資料（記事の全文、PDF、文字起こし、スクリーンショットなど）。

- **不変** — Claude はここを読むだけで、書き換えたり要約に差し替えたりしない
- ファイル名は日付や出典が分かる形にする（例: `2026-07-29_記事名.md`）
- 取り込み（Ingest）が終わったら、要約は `wiki/summaries/` に別ファイルとして作る。ここの原本は消さない

現時点ではまだ何も入っていない。次に何かをこの vault に取り込むときは、まずここに元データを置くところから始める。
