(1/2) Jev をいろいろ試していたら、jev ext-tool の問題がいくつか見つかったので、その修正を agmsg 1.4.2 に入れて出しました。

1.4.0 の記事で書いた、安全フックのログ 889 件を jev に判定させるやつ、あれをそのあとも試行錯誤していたんですよね。で、いじっていると出てくるもので、まとめて投げると答えが1行にべたっとつながって返ってくる、100 問のうち1問が崩れると全部エラーで落ちる、送りすぎると HTTP 400 としか言ってくれない、の3つに当たりました。全部直しています。

今回いちばん大きいのは、1通に何十問も入るようになったことだと思っています。1.4.0 の記事では「0.2秒で答えるツールに、返事を受け取るために1ターン払うのは高い」と書いたのですが、1通に 100 問、たとえばファイルから 100 行取ってそれぞれを判別する、みたいなことができるなら話が変わります。エージェント同士のやりとりの途中で、思いついたときに「この 50 件、jev に聞いといて」と投げても、もとが取れるようになりました。

1通にどこまで入るかも、実際の API で測ってあります(2択なら 100 問で 0.5 秒、77 択は 45 問が上限、計測全体で1セント)。何が問題で、どう直して、自分で試すにはどうすればいいかは、記事にまとめました。
