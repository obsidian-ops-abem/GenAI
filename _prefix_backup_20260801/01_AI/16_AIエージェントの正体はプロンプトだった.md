# AIエージェントの正体はプロンプトだった

> [!info] 出典
> 織田信長ポンテッセ([@oda_nobunaga10](https://x.com/oda_nobunaga10)) 2026-07-30 投稿
> [元記事](https://x.com/oda_nobunaga10/status/2082447124676186425)
> 詳細メタデータ: [[20_AIエージェントの正体はプロンプトだった（出典）]]

「AIエージェント」というと特別な仕組みを想像しがちだが、**その実態はほぼ「プロンプト」にすぎない**、と喝破する概念解説。エージェントの「自律性」も、中身は丁寧に組み上げられた指示の連鎖であることを明らかにする。

## 核心：「エージェント ＝ 高度に構造化されたプロンプト」

よくある誤解と、著者の主張を対比すると：

| 誤解 | 著者の主張 |
|---|---|
| エージェントは「自律的に考えて動く特別なAI」 | 自律性の正体は、**綿密に書かれたプロンプト** |
| 特別なモデル・魔法のような仕組みが必要 | 既存のLLMに**振る舞いを指示するプロンプト**で実現できる |
| AI自身が勝手に判断している | 判断の枠組みは**人間がプロンプトで設計**している |

つまりエージェントとは、**「思考プロセス・行動選択・ツール利用の判断基準」をすべてプロンプトに書き下したもの**。神秘的な「自律性」ではなく、設計された「ルールの連鎖」。

## エージェントを形作るプロンプトの要素

著者が挙げる、エージェント性を生み出すプロンプト構成要素：

| 要素 | 役割 |
|---|---|
| **役割（ロール）** | 「あなたは〇〇の専門家です」等、振る舞いの前提を与える |
| **目標** | 何を達成すべきかの明確なゴール |
| **制約・ルール** | やってよいこと・やってはいけないことの境界 |
| **思考手順** | どう考え、どう判断するかのステップ（推論の道筋） |
| **ツールの使い分け** | どの状況でどのツール（検索・計算・実行等）を使うか |
| **停止・確認のタイミング** | いつ自力で進め、いつ人間に戻すか |

これらを組み合わせることで、AIはまるで「自律的に動いている」ように見えるが、**実態はプロンプトが細かく指示しているだけ**。

## なぜこの見方が重要か

- **「魔法」として諦めない** — エージェントは設計可能で改善可能
- **プロンプトが設計図** — 振る舞いを変えたければ、プロンプトを直すのが本質
- **再現性がある** — 同じプロンプト構造を使えば、同じエージェント性を再現できる
- **ブラックボックス化を防ぐ** — 「AIが勝手に」ではなく「このルールで動いた」と把握できる

## 実務への含意

- エージェントが期待通り動かないとき、**モデルのせいにする前にプロンプトを見直す**
- エージェント開発のスキル ＝ **プロンプトで思考プロセスを設計するスキル**
- 複雑なエージェントも、**「分解してプロンプトに落とす」** ことで構築できる

## まとめ

- **AIエージェントの正体は、高度に構造化されたプロンプト**
- 自律性・判断力は魔法ではなく、**人間がプロンプトで設計したルールの連鎖**
- エージェント開発 ＝ プロンプト設計。改善の矛先もプロンプトにある
- 「AIが勝手に動いた」というブラックボックス観を脱し、**設計可能なものとして捉える**のが本質
