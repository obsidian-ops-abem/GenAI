# Agent Skillsを作る完全プロンプト

> [!info] 出典
> にも｜AIによって爆誕([@ai_ai_ailover](https://x.com/ai_ai_ailover)) 2026-07-23 投稿
> [元記事](https://x.com/ai_ai_ailover/status/2080152220788838563)
> 詳細メタデータ: [[02_Agent Skillsを作る完全プロンプト（出典）]]

35万回以上閲覧された、**Agent Skills（Claude / Codex などで使える再利用可能なスキル定義）を作るための完全ガイド**。「いざClaudeやCodexを開くと最初の一言で止まる」「SKILL.mdに何を書けばいいのか分からない」という悩みに対し、コピペするだけでAIが要件を聞き出してSKILL.mdを書いてくれる**対話型プロンプト**を提供しているのが最大の特徴。

## そもそも Agent Skills とは

- Claude・Codex・Cursorなど主要AIツールで共通して使える「**再利用可能な指示のセット**」
- ファイル名は原則 `SKILL.md`。Markdown形式
- やりたい作業をまとめておけば、毎回同じ説明をしなくて済む
- 一度作れば複数ツールで使い回せる「**資産**」になる

> [!note] 記事の立ち位置
> Skillsの概念解説だけでなく、**「AI自身にSKILL.mdを書かせる」ためのプロンプト**を実践例付きで配布している点が本記事の核心。

## コアメソッド：対話型プロンプト

記事が提供するのは、**ユーザーがそのままコピペするだけで、AIが逆質問しながら要件を引き出し、最終的にSKILL.mdを完成させてくれる**プロンプト。プロンプトの骨子は次の構造（記事から要約）。

```
あなたはAgent Skills作成の専門家です。
以下の手順で、私のやりたいことをSKILL.mdとしてまとめてください。

1. まず私に「何を自動化したいか」を3〜5個の質問で聞き出す
2. 私の回答をもとに、SKILL.mdの構成案を提示する
3. 私がOKするまで、不足分を追加質問しながら詰める
4. 最終的に完成したSKILL.mdをコードブロックで出力する
```

### このプロンプトの利点

| 利点 | 説明 |
|---|---|
| **最初の一言で止まらない** | 「何を作りたいか」をAIが質問してくれるので、白紙から書かなくてよい |
| **要件漏れを防げる** | 対話で引き出すので、自分でも気づいていない条件を洗い出せる |
| **品質が安定する** | 専門家ロールを与えることで、SKILL.mdの書き方のベストプラクティスが反映される |
| **初心者でも作れる** | Skillsの知識がなくても、質問に答えるだけで完成する |

## SKILL.md の推奨構成（記事の指針）

記事は、完成したSKILL.mdに最低限盛り込むべき要素として以下を挙げている。

| セクション | 役割 |
|---|---|
| **概要・目的** | このSkillが何を解決するかを1文で |
| **トリガー条件** | どんなときにこのSkillを発動するか |
| **前提・入力** | 必要なファイル・情報・環境 |
| **手順** | 実際の作業ステップ（番号付きで明確に） |
| **出力形式** | 最終成果物をどういう形で出すか |
| **注意事項・制約** | やってはいけないこと、エラー時の挙動 |

### よくある失敗と対策（記事より）

- ❌ **ルールを大量に書きすぎる** → AIがどれを優先すべきか迷う。重要度順に絞る
- ❌ **抽象的な指示** → 「いい感じに」ではなく具体的手順を書く
- ❌ **一度書いて放置** → 使いながら更新する。SKILL.mdは生き物
- ✅ **実例（example）を添える** → 入出力の具体例があると精度が跳ね上がる

## 実践ワークフロー

記事が推奨する、Skillを作って運用するまでの流れ。

```
1. 上記プロンプトをClaude/Codexに貼る
2. AIの質問に答えて要件を言語化
3. SKILL.mdの構成案をレビュー → 調整
4. 確定したSKILL.mdを .claude/skills/ 等に保存
5. 実際に使ってみて → 微修正を繰り返す
6. 満足したら他のAIツール（Cursor/Codex等）にも流用
```

## 応用：作りたいSkillの例

記事で挙げられている・作れそうなSkillの例。

- 毎週の週報を自動生成するSkill
- コードレビューを一貫した基準で行うSkill
- 論文要約を決まったフォーマットで出すSkill
- 新規プロジェクトのディレクトリ構成を瞬時に作るSkill

## まとめ

- **Agent Skillsは主要AIツールで共通使える「指示の資産」**
- 本記事の核心は**「AI自身にSKILL.mdを書かせる対話型プロンプト」**の提供
- このプロンプトを使えば、初心者でも「最初の一言で止まる」ことなくSkillを作れる
- SKILL.mdは、概要・トリガー・入力・手順・出力・制約 の6要素を押さえ、実例を添える
- 作って終わりではなく、**使いながら育てる**のがコツ
