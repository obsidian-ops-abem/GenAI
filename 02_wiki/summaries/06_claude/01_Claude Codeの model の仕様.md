Claude Codeの /model の仕様について、あんまり知られてなさそうだったので共有

通常の /model からモデルを変更すると、並列で開いている複数のセッションに影響します。

そのセッションだけモデルを指定したい場合は、/model でモデル選択時に\`s\`で決定する、もしくは起動時に --model オプションで指定すると、他のClaude Codeのセッションに影響しないです。

e.g.)

claude --model fable
