# LLM 構築講義 — 事前訓練から DPO まで

> **LLM 構築の5要素（アーキテクチャ/損失/データ/評価/システム）のうち実務で効くのはデータ・評価・システム。データパイプライン（Wikipedia 参照分類器・ドメイン重み付け）・スケーリング則（Chinchilla 20トークン/パラメータ・Llama3-405B≈7,500万ドル）・SFT はフォーマット学習（LIMA）・ハルシネーションの SFT 起源仮説・DPO は PPO と同最適解で実装が桁違いに簡単・LM as judge は人間の50倍安く一致率も上（ただし長さバイアス制御要）。**

出典: [[120_LLM構築講義 事前訓練からDPOまで（出典）]]（Stanford Alpaca チーム関係者。本文はユーザー提供トランスクリプト tc/output/20260929_081451 から主題別に再構成）

## 一行で

Stanford の Alpaca チーム関係者による LLM 構築の全体像講義。pre-training（トークナイザー・データ・スケーリング則）から post-training（SFT→RLHF→DPO→LM as judge）まで、実務の数字つきで押さえる基礎講座。

## 核心知見（抜粋）

| トピック | 要点 |
|---|---|
| **5要素** | 学術界はアーキテクチャ/損失に集中しすぎ。**実務で効くのはデータ・評価・システム** |
| **トークナイザー** | BPE（最頻ペア反復マージ）。**数学が苦手なのは数字がトークン化され合成できないため**。GPT-4 の大変更点=コードのトークン化 |
| **データ** | Wikipedia 参照ページ由来かを分類する分類器で濾過。**コードを増やすと推論が向上**。終盤は高品質データで低学習率 |
| **スケーリング則** | 小モデルで則を当てはめ外挿→巨大モデルを長く訓練。**アーキテクチャ小差は切片だけ（10時間長く訓練が勝る）。良いデータは則自体を改善** |
| **Chinchilla** | 訓練最適=20トークン/パラメータ・**推論考慮=150**（小モデルを長く使う方が安い） |
| **Llama3-405B** | 3.8e25 flops（**1e26 の規制審査線をわざと下回る**）・16k H100×70日・**計約7,500万ドル** |
| **SFT（LIMA）** | 2,000→32,000 で変わらず。**SFT はフォーマット学習**（事前訓練分布内のユーザータイプ選択） |
| **ハルシネーション起源仮説** | 人間の答えに事前訓練で知らない事実があると「もっともらしい作り話」を学習する |
| **DPO** | RL なしで選好の尤度を直接最大化。**PPO と同じ大域最適解・実装桁違いに簡単**→標準に |
| **LM as judge** | 人間との一致率 66%（人間自身と同じ）・**50倍安い**。ただし**長さバイアス**（verbose 指示だけで勝率+14.4pt）→回帰で制御 |
| **システム** | MFU 50%で上出来。混合精度（計算16bit/重み32bit）・**オペレータ融合**（DRAM 往復を1回に） |
