# LLM の数学的基礎 — トークン化から Transformer まで

> **自己回帰言語モデルを確率論から組み立てる学術講義。トークン化(BPE)→連鎖律による同時分布の条件付き分解→埋め込み行列→softmax による条件付き分布のパラメータ化→生成(温度・top-k)→負の対数尤度訓練→Transformer(single-head attention・因果マスク・multi-head)→MLP→ReLU→残差接続→LayerNorm/RMSNorm→SGD/minibatch。なぜ MLP だけでなく attention が必要か・なぜ SGD が非凸でも機能するかの理論的背景。**

## 一行で

LLM の数学的基礎を、確率論の連鎖律から Transformer の attention まで順を追って構築する学術講義。「モデルは巨大な MLP でも原理的には解けるが、パラメータ数が T に依存しすぎ実用性がないため、attention という構造を処方する」「SGD のノイズが局所最適から抜け出すという通俗的説明は否定され、高次元では悪い局所最適が稀という仮説が紹介される」など、実装だけでは得られない理論的視点が含まれる。

## 1. トークン化（BPE）

- 文字単位だとステップが多すぎ、単語単位だと希少語（internationalization・造語）で他の語からの知識转移ができない
- **subword トークン化**：共通部分語を組み合わせて理解（国際化 = 国際 + ification）
- 語彙サイズは 10^5 オーダー（Qwen3.5 で約 250k）。各トークンに ID
- **BPE（byte pair encoding）**：貪欲算法で頻出部分語を順に統合して語彙を構築

## 2. 自己回帰確率モデル（核心）

長さ T のトークン列の同時分布は V^T 個の組み合わせ（V=語彙サイズ）。すべてに1つずつ確率を割り当てるのはパラメータ過多。**連鎖律で条件付き確率の積に分解**：

```
P(x_1...x_T) = P(x_1) · P(x_2|x_1) · ... · P(x_T|x_1...x_{T-1})
```

各条件付き分布は V 個の選択のみ → softmax でパラメータ化。この softmax の前のベクトルを **logits** と呼ぶ。

- 入力：トークン ID → 埋め込み行列から D 次元ベクトルを読出し（行ベクトル）
- 変換：Transformer（次節）が `x_0...x_{t-1}` → `u_t`（V 次元 logits）を計算
- 分布：`P(x_t = j | x_0...x_{t-1}) = softmax(u_t)[j]`

## 3. 生成（復号）

- 開始トークン `x_0` から `u_1 = f_θ(x_0)` → softmax からサンプリング → `x_1` → `f_θ(x_0,x_1)` → ... を繰り返す（**autoregressive** の語源）
- **温度 τ**：logits を τ で割る。τ→0 で分布は鋭くなり決定論的（argmax に近い）・τ>1 で平坦化し多様性増加
- **top-k サンプリング**：上位 k 個のトークンだけ残して再規格化

## 4. 訓練（負の対数尤度）

```
L(θ) = -log P_θ(x_1...x_T) = -Σ_t log[ softmax(f_θ(x_0...x_{t-1}))[x_t] ]
```

各時刻の softmax から**実際に観測されたトークン `x_t` の確率**だけを取り出して log → 和 → 符号反転。Adam 等のオプティマイザで最小化。

→ 分類問題の **cross entropy 落とし**と同型。回帰問題ではガウスノイズ仮定で二乗誤差に一致。

## 5. Transformer の全体構造

```
embedding → [attention → MLP]×N → logits
```

- **attention**：系列→系列。位置間の相互作用（情報融合）を担う唯一の構造
- **MLP**：各位置のベクトルを独立に処理（位置間依存なし・並列可能）
- この交互を N 繰り返して最終ベクトル列を出力

### なぜ MLP だけでだめなのか（理論的ポイント）

- 各トークンを独立処理するだけでは文の依存関係を捉えられない
- 巨大 MLP で全部結合しても原理的には可能だが、**パラメータ数が系列長 T に依存**しすぎ（T=百万で百万×百万行列）。訓練時 T=1000・テスト時 T=1001 でパラメータ数が変わる問題も
- attention は**パラメータ数が T に依存しない**構造を保ちつつ十分な柔軟性を残す（平均だけだと構造を過剰に処方）

## 6. Single-head Attention（核心）

各入力 `h_t` に3つの射影行列を掛けて **query/key/value** を生成：

```
q_t = h_t · W_Q,  k_t = h_t · W_K,  v_t = h_t · W_V
```

位置 t の出力は：
1. `q_t · k_i^T`（query と各 key の内積）で類似度スコア
2. softmax で確率ベクトル `p_t1...p_tT`（規格化）
3. `h_t^out = Σ_i p_ti · v_i`（値の確率的重み付き平均）

query は「何を探すか」、key は「何が関連するか」のマッチングに相当。内積が大きい位置ほど高い注意を払う。

### 因果マスク（causal masking）

上記では時刻 t が未来の `k_{t+1}` を見てしまう。**上三角に -∞ を足す**ことで softmax 後にゼロ化し、未来を参照できないよう制約。自己回帰の整合性を保つ必須の仕組み。

## 7. Multi-head Attention

single-head を H 個並列（重み行列は異なる）→ 各 head の出力を結合 → 射影行列で統合。

直観：各 head が異なる種類の情報（エンティティ・感情・構文等）に注意を向ける。100B パラメータモデルで約100 head。

## 8. 計算量とメモリ

- attention の `QK^T` は T×T 行列 → **メモリ O(T²)**
- **FlashAttention**：行列全体を作らず部分ごとに計算してメモリフットプリントを削減
- アーキテクチャ変更で T への依存を減らす手法もあるが、表現力低下のトレードオフ

## 9. ニューラルネットワーク基礎（活性化・積層）

### ReLU（rectified linear unit）
`ReLU(t) = max(t, 0)`。線形 + ゼロ以下の切断で非線形性を導入。脳の発火閾値の粗いアナロジー（「activation」の語源）。

### 層の積層
```
a = ReLU(W_1 · x + b_1)   # W_1 は m×d
y = W_2 · a + b_2          # W_2 は ?×m
```
中間表現（例：walkability・school quality）を生の入力（size・bedrooms・zipcode）から自動抽出。次元の整合性：出力次元が次層の入力次元になる。

## 10. 残差接続（residual connections）

```
z_next = z + MLP(ReLU(MLP(z)))
```

動機：ある程度目的に近づいたら、ネットワークに**残差（差分）だけを学習させる**方が容易。ResNet 論文。最適化の conditioning 改善という説明もある（講師自身の論文を含む）。ブロック数は2〜3層が実証的に最適。

## 11. LayerNorm / RMSNorm

- **LayerNorm**：`β + γ · (z - μ̂)/σ̂`。平均0・分散1に正規化後、学習可能な β/γ で再調整
- **RMSNorm**：平均引を省き `β + γ · z/σ̂` だけ。LLM で主流（計算安価）
- 効用：**スケール不変性**（入力に定数を掛けても出力が変わらない）で安定化。層を重ねるごとに値が爆発するのを防止
- 副作用：前向きはスケール不変だが勾配は不変でない（高次の問題）

## 12. SGD と minibatch（最適化の理論）

- 完全バッチ勾配降下は1兆トークン全ての勾配を計算する必要があり非現実的
- **SGD**：1例（または小バッチ）の勾配を平均の不偏推定として使う。ノイズは大きいが期待値は一致
- **minibatch**：ノイズ低減＋GPU 並列活用

### SGD ノイズが局所最適から抜け出す、という通説の否定（重要）

講師は「SGD のノイズで局所最適から脱出する」という説明を明確に否定。コミュニティもそう信じていない。真の仮説：

- **高次元では悪い局所最適が稀**（Hessian が全方向で半正定値となる条件は極めて制約的）
- 停留点は多数あっても、それは大域最適と同値であることが多い（講師自身の研究を含む理論的計算あり）
- ノイズは脱出の役には立たないが、各サンプルの勾配は高相関なので無駄な計算を避ける実用的根拠はある
