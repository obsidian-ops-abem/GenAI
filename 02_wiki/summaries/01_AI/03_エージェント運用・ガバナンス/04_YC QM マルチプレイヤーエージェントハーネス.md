# YC QM —— マルチプレイヤーエージェントハーネス

> **「会社全体（会計・法律・イベント・エンジニアリング）で使うマルチエージェントハーネス」** — Y Combinator が社内で使っていたエージェント基盤を MIT で公開。クラウドファースト・Slack/UI ネイティブ・企業ブレイン。

出典: [[54_YC QM マルチプレイヤーエージェントハーネス（出典）]]（Y Combinator @ycombinator, 2026-08-01。本文はユーザー提供クリップから再構成）

## 一行で

**Y Combinator が社内で使用していたマルチエージェントのハーネス「QM」を MIT で OSS 化**（yc-software/qm）。Hermes・OpenClaw のようにカスタマイズ可能だが**会社全体で役立つ**（会計・法律・イベント・エンジニアリング）ことを意図。クラウドファースト・Slack とウェブ UI ネイティブ・企業ブレイン用コネクタ・マルチプレイヤープロジェクト。

## 核心: 会社全体で動くマルチプレイヤーハーネス

エージェントハーネスは多数あるが、QM の特徴は「**会社全体で役立つ**」ことを明示している点。単一用途（コーディング等）でなく、会計・法律・イベント・エンジニアリング横断で、複数人が同じプロジェクトを操作する（マルチプレイヤー）。

## 機能

| 機能 | 内容 |
|---|---|
| **トリガー** | cron・ウェブフック |
| **メモリ・共有ファイル** | エージェント間の状態共有 |
| **企業ブレイン用コネクタ** | 社内知識への接続 |
| **エージェントブラウザサポート** | ブラウザ操作 |
| **共有可能なウェブアプリアーティファクト** | デプロイ済み成果物を共有 |
| **マルチプレイヤープロジェクト** | 複数人でのプロジェクト操作 |

## アーキテクチャの指摘（コメント欄）

- **@XiJin12**: アーキテクチャ図を見ると **「decouple the brain and hands（脳と手を分離）」戦略**を採用。判断（脳）と実行（手）を分離するマルチエージェントの定石
- **@gpolzer**: メトリクスのオントロジー（正しいソースから正しい答えを引く仕組み）が必要 —— さもなくば GMV をランダムな Excel から引く事故が起きる
- **@binsquares**: 「webアプリをデプロイして」と頼むと**自律的に構築・デプロイし共有リンク付き**で返すことを実演

## 類似品

## 本ボルト内の位置付け

**エージェント運用・ガバナンスの企業スケール基盤**。03_エージェント運用・ガバナンス カテゴリ。本ボルトのハーネス系ノート群の「企業運用版」:

- [[01_エージェントファクトリの作り方 ビルダーズガイド]]（工場思想・5ステーション）が「エージェントを工場として設計」するなら、QM は**工場を会社全体（非エンジニア含む）で運用するプラットフォーム**。会計・法律・イベントなどエンジニアリング外での活用を明示
- **「decouple the brain and hands（脳と手を分離）」** は [[03_Learn Claude Code ハーネスエンジニアリング学習]]（ハーネスの5領域・許可システム）や [[04_自己レビューエージェントのGraph設計 Anthropicメソッド]]（judge と worker 分離・見えない2人のレビューア）の「判断と実行の分離」と同思想
- **クラウドファースト・Slack UI ネイティブ** は、[[08_スマホからPCのcodexとccをリモート操作]]（スマホから操作・アクセス層）や [[05_Vibe Kanban コーディングエージェント用Kanbanワークスペース]]（人間側 UI）の企業版。非エンジニアが Slack からエージェントを触る
- **企業ブレイン・メモリ・共有ファイル** は、本ボルトの CLAUDE.md・index.md/log.md（組織の記憶）や [[04_カーパシーのObsidian活用術 30分で第二の脳]]（プロジェクト記憶）の企業版。会社の知識をエージェントが引ける構造
- **メトリクスのオントロジー（@gpolzer の指摘）** は、エージェントが憶測で答えるのを防ぐ企業ガバナンス。[[04_自己レビューエージェントのGraph設計 Anthropicメソッド]]（judge・ルールブック・ルール引用強制）のデータ版 ——「正しいソースから引く」強制
- **マルチプレイヤー** は [[03_Graph of Loops Claude Code完全システム10リポジトリ]]（agent-worktree）・[[09_ephemeral-sandbox 並列エージェント用OSSサンドボックス基盤]**（並列ワークスペース）が「エージェント同士の協調」なら、QM は「**人間同士＋エージェントの協調**」を企業スケールで
