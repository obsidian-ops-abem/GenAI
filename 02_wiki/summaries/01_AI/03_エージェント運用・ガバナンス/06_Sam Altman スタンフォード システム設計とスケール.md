## 一行で

OpenAI CEO Sam Altman がスタンフォードのシステム設計クラスで語った Q&A。**スケールは独自の品質（創発特性）を持つ**という経験則を軸に、ChatGPT 誕生秘話（API で製品見つからず→チャットに使う人が多い→YC 原則「よく使うものをやる」→5日目に緊急宣言）、AI を電気のユーティリティ化に擬え「光（light）を売る」相当を見つける課題、今後10年の3分岐（民主化80%・分散コンピューティング・市民富裕基金）を論じる。

## 核心: スケールの創発特性

> なぜこれが真なのか、満足のいく理論は持たないが、**経験的には真**。キャリアで見た最も興味深いものはすべてスケールの創発特性か、コンセンサスが「機能しない」と思うはるか先までスケールが回报し続けることと関連していた。

- AI モデルのスケールだけでなく、**賢い人を集める・企業・YC バッチ内ネットワーク効果**などあらゆる領域で観察
- YC で「バッチを10社に減らせ」という賢人たちの声に逆らい、スケールした結果、**誰も発見していなかった創発特性（バッチ内ネットワーク効果）**が現れた
- スケールできる機会を見つけたら深く探索すべき

## 1. システム設計: スケールは壊れる・人間が一番難しい

- スケールすると**予測不能に加速して壊れる**
- 「 ambitions にやりすぎない」と言う賢い人が常にいる
- 10万・20万 GPU は前例がなく、エンジニア・資本・研究者文化など**各障害を1つずつ分解して対処**
- **人間参加型のシステム設計が最もリファクタ困難**。明確なゴール・計画・意思決定方法が必須
- **人間は指数関数的思考に進化していない**。第一原理から推論するのに時間がかかる

## 2. ChatGPT 誕生秘話（YC 原則の実践）

```
GPT-3（面白いが製品見つからない）
  → API にして「誰かが製品を見つけるのを待つ」（2020年夏）
    → 1ヶ月後バイラル化。しかし GPT-3/3.5 は当時の興味の割に驚くほど悪い
      → 人々は API を製品でなく「チャット」に使っていた
        → GPT-4 完成済み・3.5の中間モデル・post-training（instruction following）発見
          → YC 原則「よく使われるものをやる」→ チャットボット構築
            → 爆発的バイラル。5日目に「緊急。会社と製品を一度に構築」
              → 2ヶ月の猛烈スケール。計算費が尽きないよう課金（長期答えでないが機能）
```

> YC の学び: **本当に成長し始めたものがまだ良くない時、保証されたヒット**。

## 3. AI をユーティリティ（公共事業）として売る

> 電気・インターネット・水のようなユーティリティを作る過程にいる。これはあまり起こらない。

電気のユーティリティ化の比喩:
- 電力会社は「電気を売る」と言わなかった（怖い・何か分からない）
- 代わりに **「光（light）を売った」**。「得るのは電気でなく光。同じもので洗濯も someday」
- **OpenAI も「インテリジェンスを売る」は今のところ共鳴しない**。「光」に相当するものを見つける必要がある

## 4. アイデンティティの罠

- 特定の信念にアイデンティティを結びつけると、**科学や経験的結果が否定しても手放せず真実が見えなくなる**
- 「LLM は機能しない」と言い続けるトロールは、データが強く OpenAI 側にあるのに依然として否定
- 両方向にとって重要なリマインダ

## 5. 教育への懸念

- ChatGPT ローンチ時、1年のチート期間後に教育システムが再設計すると予想
- しかし **3年半経っても体系的変化なし** —— 予測ミス
- pre-AI のように教え評価し続けると**批判的思考力の萎縮**
- 思考を学ぶために機械が上手にできることを教える価値（書く・プログラミング）はあるが、それ以外は完全に変えるべき

## 6. 今後10年の3つの分岐

### 分岐1: 民主化 vs 少数企業集中（確率 80% 民主化）
- デフォルトは少数企業集中・地球の富の显著な割合を握る —— 明らかに悪い
- 少数集中は**アラインメント失敗で非常に脆弱な世界**
- リスクを負ってでも SF のような未来を目指すべき。**少数集中は許容すべきでない**
- 80%民主化パスだが、強い安全メッセージと権力集中希望者が対抗

### 分岐2: 分散コンピューティング
- 計算資源不足は深刻化・さらに悪化。**計算が最も重要なユーティリティ**になる可能性
- 価格が高騰しすぎた時、「分散コンピューティングとは何か」の面白い分岐
- モデルが十分賢く低コストなら需要は**事実上無限**。「優れた個人エージェント100個欲しい」→ 大量推論 → 計算不足は永遠に続く可能性

### 分岐3: 経済モデル —— 市民富裕基金
- UBI（月々固定現金）よりも**所有権ステーク（citizens' wealth fund）**に興味
- レバレッジが労働から資本へ移り続ける中、**資本のスライスを所有**する仕組み
- 起業家がスタートアップに投資した結果を見てきた。どちらが良いかはデータが示す

### 計算資源不足の現在
- H100 と Blackwell の長期予約とスポットの価格差は約5倍。H100 は今年ほぼ売り切れ
- **人々はもっとパニックすべき**
- 電力と同様、価格が下がれば需要は全く異なる水準に

- **「人間は指数関数的思考に進化していない」** は、[[13_Graph Architectへの20ステップ5フェーズ]]（Step 19 グラフにしない判断・過剰設計の罠）や [[10_Graph Engineering 最大の間違い Loop↔Graph判断]]（ループはデフォルト・過剰グラフ化の警告）と同じ「人間の認知バイアスへの警告」。Sam は「指数関数」・Graph 系は「過剰設計」がそれぞれ人間の罠
- **ChatGPT 誕生の「よく使われるものをやる」** は、[[12_カーパシーのObsidian活用術 30分で第二の脳]]（人間の意志を設計から外す・使われる形にする）や [[04_YC QM マルチプレイヤーエージェントハーネス]]（企業全体で役立つ）と同思想。**設計者が決めるのでなく、観察された使用パターンに従う**
- **「AI をユーティリティとして売る・光を売る」** は、[[05_Company OS 自律型企業運営のアーキテクチャ]]（企業の基幹業務を自律的にこなす OS）・[[04_YC QM]]（会社全体のハーネス）の上位概念。「インテリジェンスそのもの」でなく「光」相当の具体的应用を見つける課題は、Company OS/QM がその候補
- **「アイデンティティの罠」** は、[[14_自己レビューエージェントのGraph設計 Anthropicメソッド]]（見えない2人のレビューア・ルールブック）の「自信でなく証拠でループする」の哲学版。**信念にアイデンティティを結ぶと真実が見えなくなる**
- **「計算資源不足が永遠に続く」** は、[[12_Graph Engineering with Claude 14-Step roadmap]]（step12 model tier・安いモデルで退屈なノード）・[[14_自己レビューエージェントのGraph設計 Anthropicメソッド]]（役割でモデル選ぶ・コスト別チェック配置）の根拠。計算が制約だからこそ**グラフ構造でモデルを tier 分け**する実践が生まれる
- **「分散コンピューティングの分岐」** は、[[09_ephemeral-sandbox 並列エージェント用OSSサンドボックス基盤]]（共有ベース+隔離ワークスペース）・[[08_スマホからPCのcodexとccをリモート操作]]（ローカル PC の計算をリモート活用）等の「計算を分散させる」実践の背景
- **「市民富裕基金・所有権ステーク」** は AI の社会的影響のガバナンス。本ボルトでは直接技術でないが、[[01_エージェントファクトリの作り方 ビルダーズガイド]]（4自律ティア）の最上位（完全自律が社会単位に拡張された議論）
- **「pre-training/mid-training/post-training のパイプラインは major rewrite が来る」** は、[[16_LangGraphワークショップ 信頼性のあるエージェントの構築とテスト]]（Chain vs Agent vs LangGraph・trajectory 評価）のモデル訓練側の対応。アプリ側のオーケストレーション再編と並行して、訓練パイプラインも再編される
