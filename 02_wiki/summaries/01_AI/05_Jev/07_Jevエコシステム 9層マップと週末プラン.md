# Jev エコシステム — 9層マップと週末プラン

> **ローンチ7日で Jev はツールから「誰も計画しなかったプラットフォーム」へ。9層（オープンクローン/ローカルランタイム/互換サービス/ブラウザ+コンピュータ利用/ルーター/消費者アプリ/evals/SDK/本番統合）。決定モデルの競争軸は賢さでなく「形（shape）」— 再現可能なインターフェースがエコシステムを呼ぶ。独立 evals（jevals.com・31,500人手ラベル）: yes/no・choice で top-2/7・価格の端数・p95 653-693ms が正直な数字。「完全自律が製品でない。エージェント内部の安く速い条件反射が製品」。**

## 一行で

Jev ローンチ7日後のエコシステム全体地図。9層×代表プロジェクト×正直な数字（ウソと本当の境目）+ 週末でできる最初の実験プラン。

## なぜエコシステムが形成されるか

チャットモデルのローンチは「誰が賢いか」で競う。**決定モデルのローンチは「形（shape）」で競う**。Jev のリクエスト/レスポンス形は小さく再現可能で「Jev-compatible」が機能するラベルに。3つの力: **①ロックイン恐怖**（ウェイト非公開→ローカル代替はリスク台帳の1行）②**決定層はスタックのどこにも収まる**（毎セッション数千の小選択）③**誰かが採点しなければならない**（evals が3日目に到着）。

採用: Vercel AI Gateway 史上最速 — 24時間で有料チーム約13%（GPT-5.6系の2倍超・Fable 5.1 の6倍超）。

## 9層（要点）

| 層 | 代表 | 核心 |
|---|---|---|
| 1 オープンクローン | Laya(421M)・**Kev(Qwen2.5-0.5B・MacBookで訓練)**・Jevlike(**40KB**) | 2日で6実装=**アイデアは再現可能・差は実装品質**。Kev はドメイン外で Jev に19点差 |
| 2 ローカルランタイム | laya-mlx(13.42ms@M3 Max) | 1Kトークン+20ms未満ならローカル候補。32K/較正なら hosted |
| 3 互換サービス | LocalJev | **クライアント保持・上流だけ交換**（`TYPESAFE_BASE_URL` 上書き）。ただし prompted JSON で直接 logit でない |
| 4 ブラウザ+コンピュータ利用 | jev-ultrafast(Browser Use) | 操作ヘッド+対象ヘッドを**1リクエスト**。DOM テーブル方式・スクショなし。**DONE は成功の証明でない** |
| 5 モデルルーター | jev-router | 毎ターン3問（tier/effort/risky）。**非対称閾値: 昇格0.3・降格0.6**。ルーティングは生成でなく決定 |
| 6 消費者アプリ | Needle・HA-Jev | 会話 UI の下の高速層。**「どの20決定を100msで回せるか」が設計問い** |
| 7 Evals | **jevals.com**（独立） | 31,500人手ラベル・7モデル。**参照モデルでなく人間ラベルに採点** |
| 8 SDK | Python/TS・Go・Swift・R・MCP・SQL | 好きな言語から |
| 9 本番統合 | Vercel・LangChain・duckdb-jev | 既存システム内 |

## 正直な数字（マーケティングと実測の境目）

- **yes/no・choice で Jev は top-2/7 を価格の端数で達成**（GLM-5.3 60.6・Qwen3.8 62.4 等と比較）
- **順序ルーブリック（Score）では誰も当て推量を超えていない**（Jev の9.2が最高だが本番.ready でない）
- **p95 653-693ms が計画すべき数字**（「70ms」は西海岸計測のマーケ数字）
- Laya「50倍速い」= 方法論非公開の単一ポスト。リポジトリ自身の数字だけ再現可能
- OSWorld 2.0: 最良のコンピュータ利用エージェントも長期タスク20.6%。**「Jev はそれを直さない。ループの最遅部（アクション毎のモデル呼び出し）をサブ秒の有界決定で置き換える。完全自律が製品でない。安く速い条件反射が製品」**

## 週末プラン

1. **候補の3特性**: よく呼ばれる・有界な選択肢・間違っても安い
2. **質問を先に書く** — **悪い質問は実務低パフォーマンスの第1位の原因で、完全に自分で制御できる**。良い Noul は証拠を名指し（「既に支払った金の返金を要求しているか」）・悪いのは曖昧（「緊急か?」）
3. 呼ぶ（timeout=2秒）
4. **閾値+エスカレーション**: ≥0.85 自動／≥0.60 フラグ付き／未満人間。**較正済み確率が製品・生の回答ではない。閾値は自分のログから。1日目から全決定の確率をログ**
5. Mac なら kev のローカルレーンを並行
