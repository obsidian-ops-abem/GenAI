# 科学論文での図表作成のルール

> [!info] 出典
> 荒瀬康司、人間ドック Vol.38 No.5 pp.659–676, 2024
> [元資料（J-STAGE）](https://www.jstage.jst.go.jp/article/ningendock/38/5/38_659/_article/-char/ja)
> 詳細メタデータ: [[16_科学論文での図表作成のルール（出典）]]

医学論文における図表作成の実用的作法を、**全体20ルール ＋ 表20ルール ＋ 図5ルール**で体系的にまとめた解説。査読・執筆経験に基づく。「論文は後から読む人に知見を正確に伝えるもの」という前提に立ち、図表を本文の**補助**として位置づける。JIS X 4051（日本語文書の組版方法）に準拠。

## 基本姿勢

- **主役は文章**。図表は複雑な情報を効率よく伝える補助ツール
- **データの正確性**（本文との数値・単位・方法の一致）が論文の信頼性の根幹
- **読み手への配慮**（タイトル・番号・桁揃え・罫線最小化・黒1色）を徹底

## 1. 図表作成の全体ルール（20項目）

| # | ルール |
|---|---|
| 1 | **図と表の定義を確認**。表＝文字・数値と罫線で構成、図＝罫線以外の図形・写真など不定形なもの |
| 2 | **図表の役割を把握**。情報の可視化・比較・整理。ただし主役は文章 |
| 3 | **表と図の違いに注意**。結果表示は表を優先、比較・傾向・相関の強調には図。表には文章も入れられるが、図の中身は数値主体 |
| 4 | **図表は1ページに1つずつ**。そのページに本文は書かない |
| 5 | **引用図表には出典明記**（著者名・タイトル・雑誌名・発行年・所在ページ） |
| 6 | **本文・図・表は重複させない**。表に全内容を書くなら本文は「詳細は表○に示した」で簡略化 |
| 7 | **白背景に黒が原則**。特別な目的がなければ色は使わない |
| 8 | **タイトル位置は決まっている**（JIS X 4051）。表＝表の上、図＝図の下。タイトルに「キャプション」は付けない。英文は語頭のみ大文字 |
| 9 | **図表そのものが最優先**。タイトル・説明文・脚注は補助。タイトルは本文より2割大きく、太字・大文字のみは避ける。説明文にボールド・斜体は避ける |
| 10 | **図・表には必ず番号を付ける**。本文参照にも番号使用。「次の図」「上の表」は避ける。章立てなら「図1.1, 図1.2…」も可 |
| 11 | **タイトルの書き方**。番号の後は1文字分空けて中央揃え、体言止め、略語なし（例「2018年以降5年間のA健診施設での受診者数の変遷」） |
| 12 | **タイトルは固有名詞で簡略化しない**。「対象背景」「治療成果」等の意味を持たないタイトルは避ける |
| 13 | **タイトルと内容を一致させる** |
| 14 | **同種の図表で形式を統一**。罫線・フォント・列見出し・記述内容を揃える |
| 15 | **本文中で引用されていることが必要**。言及のない図表が孤立しないよう確認。引用順に番号が付くかも確認 |
| 16 | **データを間違えない**。1つの誤りが全情報の信頼性を揺るがす。「見直し」がプロと素人の分かれ目 |
| 17 | **数値の本文との不一致は厳禁**。原因は①書き間違い ②コピペ誤り ③一覧表→再解析→書き直しの不整合 |
| 18 | **単位の本文との不一致も厳禁**。本文が平均値±SD、図表が中央値±四分位など異なる表現は避ける |
| 19 | **方法も本文と統一**。検出方法などが異ならないか確認 |
| 20 | **図表は本文で必ず言及**。挿入位置は言及ページか直後のページが望ましい |

## 2. 表の作り方（20項目）

### 表の3分類

- **内容表** — 背景・結果の内訳
- **比較表** — 2群以上の比較
- **時系列表** — 時間を基準にした記載

### 構成・書式の要点

| 項目 | ポイント |
|---|---|
| **構成要素** | 表題・行/列見出し・行/列データ・脚注 |
| **左最前列を「項」に** | 左列を項とし右に数値配置。読者の視線（右上→右→下）が自然に導かれ混乱しない |
| **対象の特徴** | 実数より**パーセント表記**が読みやすい。群間で対象数が大きく異なる場合は併記 |
| **和文フォント** | 明朝体（後向き研究・重厚感）かゴシック体（見せる・親しみ・男性向け） |
| **英文フォント** | Serif（Times, Garamond＝明朝的）か Sans Serif（Arial, Helvetica＝ゴシック的） |
| **フォント統一** | 本文と図表で異なっても、それぞれの内部では統一 |
| **行送り** | 書籍では行間＝文字サイズの50–75%（行送り1.5–1.75倍）。Word標準10.5ptなら行送り18pt。表は行送り1.50倍推奨、タイトルは1.1–1.2倍 |
| **見出しの揃え** | 列見出し＝中央揃え、行見出し＝上下中央。年号は上から古い順 |
| **セル内配置** | 文字＝左詰め、数値＝右詰め |
| **列幅・行高** | 揃えるのが原則（文字数が大きく異なる場合は例外） |
| **小数点の桁揃え** | 小数点以下の桁数を統一し位置を縦に揃える（平均2桁・SD1桁など）。揃えるため0を付ける（9 → 9.00） |
| **項目の並べ方** | アルファベット順・数値大順・重要順・時系列順など合理的基準で |
| **先頭の0** | 省略可。p値等は「0.459」→「.459」でも可 |
| **空欄を作らない** | 未決定は「未決定（○月○日決定予定）」、該当なしは「―」、TBDも可 |
| **脚注** | 最小限に。順序は上→下、同行は左→右。英字記号は ＊, †, ‡, §, ¶, # の順。和文は a),b),c) や 1),2),3) も可 |
| **罫線** | 少なくする。**縦線は原則入れない**。横線は上・2番目・下の3本（太さ3,1,3pt または 3,1,1pt）。1pt＝0.35mm |
| **単位の表記** | 漏れに注意（人、%、長さ、重さ、濃度など） |
| **数値表記** | 半角英数が原則。全角「１２３４５６」は避ける |
| **桁区切り** | 3桁ごとにカンマ。ただし年号には付けない（2024年、×2,024年） |
| **大きな数値** | 「万」「億」を活用（5,000万）。×50,000,000 |

## 3. 図の書き方（5項目）

### 代表的なグラフ

- **棒グラフ** — 大きさ・量の比較
- **円グラフ** — 割合（構成）の表示
- **折れ線グラフ** — 時間に対する連続的変化

用途に応じて適切に選択。上記以外にも多数のグラフが存在する。

### 作図のポイント

| # | ポイント |
|---|---|
| 1 | **研究の全体像を示す図を作る**。研究フローチャートを文章だけで伝えるのは困難。フローチャートで全体の流れが図示されていれば読解が容易になり理解が深まる |
| 2 | **多種のグラフを理解し**、強調したい点に応じて選ぶ |
| 3 | **フローチャートで研究・実験スキームを説明**。他研究者への伝達に有効 |
| 4 | **黒1色が原則**。後の人がモノクロ印刷・コピーする際、色で差別化すると識別不能になる。複数系列の区別は**パターン（斜線・点線等）**で行う。最も落ち着いた表現として推奨 |
| 5 | **折れ線グラフ**は各線の変化を認識できるように。ただし**5本以上**になると複雑化し分かりにくくなる |

## まとめ

- 図表は本文の補助であり、主役は論理的な文章
- データの正確性（本文との数値・単位・方法の一致）が論文の信頼性の根幹
- 読み手への配慮（タイトル・番号・桁揃え・罫線最小化・黒1色）を徹底
- JIS X 4051 に準拠した標準的な作法を踏襲

初心者が論文を書き始める際の実践的指針として構成されている。

> [!note] 注意
> 本文中の数値例（HCV排除、糖尿病発症率、受診者数の推移など）はルール説明のための**サンプルデータ**。特定の研究結論ではなく作例。
