# Vibe Kanban —— コーディングエージェント用 Kanban ワークスペース

> **「差分が引き継ぎポイント。レビューが別タブのままなら、ワークスペースは散らかりを動かしただけ」** — ターミナルタブでエージェントを並走させると計画よりレビューが難しくなる問題を解く。

## 一行で

コーディングエージェントの**計画とレビュー**を支援する開発者向け Kanban ワークスペース。各エージェントに専用ブランチ・ターミナル・開発サーバーを割り当て、**差分レビューをワークスペース内に閉じ込める**。

## 解く問題

ターミナルタブ間でエージェントを並走させると:
- どのエージェントが何をやったか分からない
- **実装よりレビューが難しい**
- 差分レビューが別タブに散らばる

## 5つの機能

| 機能 | 内容 |
|---|---|
| **Kanban イシュー** | ボード上で作業を作成・優先順位付け・割り当て |
| **エージェントワークスペース** | エージェントごとにブランチ・ターミナル・開発サーバーを分離 |
| **差分レビュー** | インラインコメント → エージェントへフィードバック |
| **アプリプレビュー** | 組み込みブラウザ・DevTools・インスペクトモード・デバイスエミュレーション |
| **エージェント選択** | Claude Code / Codex / Gemini CLI 含む **10+ エージェント**を切替 |

## 核心: 差分 = 引き継ぎポイント

> @DanKornas: **「The diff is the handoff point. If review still lives in another tab, the workspace has only moved the mess around.」**
> @i_mika_el: 「インライン差分フィードバックこそ、ターミナルタブが決して解決しない部分」

差分レビューをワークスペース外（別タブ・別ツール）に置いたままでは、ワークスペースは散らかりを移動しただけ。**差分をワークスペース内の第一級オブジェクトにする**ことが核心。
