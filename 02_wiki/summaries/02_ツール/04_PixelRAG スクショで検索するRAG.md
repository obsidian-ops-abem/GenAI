# PixelRAG — スクショで検索するRAG

> 「DOMを読む」より「画面を見せる」。テキスト化で失われる表・図・レイアウトを、スクリーンショット画像のまま検索・読解するRAG。

出典: [[25_PixelRAG スクショで検索するRAG（出典）]]（@cosmos_hzokujin, 2026-07-30）

---

## 一行で

WebページやPDFを**スクリーンショット画像のまま**ベクトル化して検索し、VLMに直接読み取らせるRAG手法。テキストベースRAGに比べ**最大18.1%向上**を報告。

## 従来RAGの課題

| 従来 | PixelRAG |
|---|---|
| HTMLを**テキスト化**して検索 | **スクショ画像のまま**検索 |
| 表・グラフ・レイアウトの**構造情報が喪失** | 構造情報を**視覚的に保持** |
| テキスト検索＋テキストLLM | 画像検索＋**VLM（視覚言語モデル）** |

## 仕組み（4ステップ）

1. **キャプチャ** — Webページ / PDF をスクリーンショットとして取得
2. **ベクトル化** — 画像タイルを **Qwen3-VL-Embedding** で埋め込み
3. **検索** — **FAISS** 等で近傍探索
4. **読解** — **VLM** がスクリーンショットを直接読み取って回答生成

## 実績

- 開発元から **Wikipedia の事前構築インデックス**が公開済み（すぐ試せる）
- 論文実験: **約3,000万枚**のスクショ画像で評価
- テキストベースRAG比 **+18.1%**（最大）

## 投稿者の所感

- 構造化データ抽出では **HTML / API が依然として有効**（PixelRAGで置き換えるべきではない領域）
- しかしAIエージェントにWeb・PDFを**理解させる**用途では、「DOMを読む」より**「画面を見せる」が自然**なケースが増加中
- 表・図・PDF取り扱いで困っている人向け
