# 認証基盤リプレース

## 概要

自前実装のセッション管理を OIDC ベースへ寄せる。目的は運用コスト削減と、監査ログの一元化。

## 決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| プロトコル | OIDC (Authorization Code + PKCE) | モバイル含めて単一フローで済む |
| トークン保存 | HttpOnly Cookie | XSS 経由の持ち出しを防ぐ |
| 移行方式 | 二重稼働 → 段階切替 | ロールバック余地を残す |
