# Langflow ビジュアルAIワークフロービルダー

> [!info] 出典
> [langflow-ai/langflow](https://github.com/langflow-ai/langflow)（GitHub、MITライセンス）
> 詳細メタデータ: [[langflow-ai langflow（出典）]]

AIエージェント・ワークフローを画面上でビジュアルに組み、そのままAPIやMCPサーバーとしてデプロイできるOSSプラットフォーム。ノードをドラッグ＆ドロップで繋いでLLMパイプラインを作るタイプのツールで、[[Graph Engineering エージェントを行列から解放する]] の文脈で言えば「Graph層（ノード・エッジ・分岐・合流）をコードを書かずに視覚的に組む道具」に当たる。

## 主要機能

| 機能 | 内容 |
|---|---|
| ビジュアルビルダー | 画面上でワークフローを組んで即座に反復できる |
| ソースコードアクセス | 各コンポーネントをPythonでカスタマイズできる（ブラックボックスにしない） |
| インタラクティブプレイグラウンド | ステップ単位でリアルタイムにテストできる |
| マルチエージェント・オーケストレーション | 会話管理・検索機能つきで複数エージェントを組める |
| API/MCPサーバー化 | 組んだフローをJSONエクスポートするか、そのままAPI／MCPサーバーとしてデプロイできる |
| オブザーバビリティ | LangSmith、LangFuseなどと統合してトレースを確認できる |
| エンタープライズ対応 | セキュリティ・スケーラビリティを考慮した構成が可能 |

## アーキテクチャ

- バックエンド: Python（約65%）
- フロントエンド: TypeScript／JavaScript（合わせて約35%）
- ライセンス: MIT（商用利用・改変・再配布が自由）

## 使い方

**ローカル実行**
```bash
uv pip install langflow -U
uv run langflow run
# http://127.0.0.1:7860 でアクセス
```

**Docker**
```bash
docker run -p 7860:7860 langflowai/langflow:latest
```

Windows/macOS向けの依存関係内包型デスクトップアプリ（Langflow Desktop）も提供されている。

## 対象ユーザー

AI/LLM統合が必要な開発者、ノーコード/ローコードでエージェントを組みたい人、エンタープライズ規模のAIワークフローを構築したい組織、幅広いスキルレベルのコントリビューター。

## 所感・関連

- [[Graph Engineering エージェントを行列から解放する]] の主張——「グラフは手描きせず、目的の記述からシステム自身に組ませる方向へ向かう」——とは逆に、Langflowは今のところ**人間が手でグラフを描く**前提のツール。位置づけとしては「今の主流」寄りで、記事が言う「次のフロンティア」とは方向性が異なる
